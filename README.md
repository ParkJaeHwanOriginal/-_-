# 📰 재단 뉴스 자동 검색 및 모니터링 자동화 프로젝트

본 프로젝트는 **광주경제진흥상생일자리재단** 인턴의 일일 반복 업무(재단 관련 뉴스 지면 검색 및 보고)를 자동화하기 위해 기획된 파이썬 기반 뉴스 스크래퍼 프로젝트입니다.

---

## 1. 프로젝트 배경 및 목표
* **배경**: 매일 출근 후 지정된 5개 신문사 사이트에서 재단 관련 키워드를 수동으로 검색하여 당일 지면 기사의 존재 여부를 파악하는 반복적인 단순 업무 수행 중.
* **목표**:
  * 별도의 PC 조작이나 수동 입력 없이 **지정된 키워드로 5개 매체를 자동 검색**.
  * 당일 올라온 뉴스 기사들의 **존재 여부 및 건수를 확인**.
  * 결과를 엑셀 파일(`news_report.xlsx`)로 **자동 누적 최신화**하여 확인이 용이하도록 처리.
  * 출근하지 않은 날에도 작동되도록 최종적으로는 **클라우드(GitHub Actions) 환경에서 자동 스케줄링** 실행 구축을 지향.

## 2. 모니터링 대상 매체 및 기술 명세

| 신문사명 | 대상 URL | 수집 방식 및 특징 |
| :--- | :--- | :--- |
| **빅카인즈 (BigKinds)** | [바로가기](https://www.bigkinds.or.kr/) | Playwright 동적 크롤링 및 최신순 정렬 후 당일 기사 추출 |
| **동아일보** | [바로가기](https://www.donga.com) | Playwright 통합검색을 활용한 기사 추출 |
| **광주매일신문** | [바로가기](https://kjdaily.wigoview.com/) | Playwright 기반 e-Book(지면뷰어) HTML 요소 매칭 분석 |
| **무등일보** | [바로가기](https://www.mdilbo.com/page/ebook) | 🚫 **[현재 수집 중단]** `requests` 및 `PyMuPDF` + `EasyOCR`를 통한 당일 지면 이미지 기반 텍스트 추출 및 대조 (로컬/깃허브 액션 수집 비활성화) |
| **남도일보** | [바로가기](https://www.namdonews.com/pdf/list.html) | `requests` 및 `PyMuPDF`를 통한 당일 지면 PDF 텍스트 정밀 대조 (초고속 메모리 직접 파싱) |

### ⚠️ 신문사별 검색 기준 시간 (검색 범위 유의사항)
* **동아일보**: 검색이 실행되는 시점을 기준으로 **최근 24시간 이내**에 등록된 기사를 검색합니다. (예: 오늘 오후 4시에 실행 시, 어제 오후 4시 ~ 오늘 오후 4시 사이 등록된 기사 수집)
  * *유의사항 (지면보도)*: 동아일보의 경우 지면보도 검색이 따로 제공되지만, (1) 실제 지면을 확인하려면 결제가 필요하고, (2) 대부분의 지면보도 건은 동일한 온라인보도가 함께 올라오므로 일반 통합 검색으로 커버됩니다. 만약 지면보도건을 별도로 추가 교차 검증해야 하는 경우, [동아일보 PDF검색 페이지](https://www.donga.com/news/Pdf)를 통해 조회하고 보도담당자(인턴담당자)에게 따로 확인을 요청하시기 바랍니다.
* **기타 매체 (빅카인즈, 광주매일, 남도일보 등)**: 실행 시간과 관계없이 **해당 날짜(자정 00:00 ~ 현재)** 또는 **당일 발행 지면 전체**를 기준으로 뉴스 및 지면을 조회합니다.

## 3. 핵심 자동화 기능 요구사항

### 📊 결과 보고 (Excel)
* **파일명**: `news_report.xlsx`
* **저장 데이터**: `검색일자`, `신문사명`, `조회 결과` (예: `기사 3건 있음` 또는 `기사 없음`)가 날짜별로 누적되어 저장.
* **사용자 시각화 지원**: 로컬 환경에서 테스트 시 크롬 브라우저가 직접 켜져 작동(Headless=False)하여 사용자가 시각적으로 크롤링 및 PDF 탐색 단계를 더블체크할 수 있게 지원.
* **남도일보 지면 확인**: 남도일보 검색 결과의 상세 지면 번호(예: `[지면 1면]`) 및 관련 본문 정보는 엑셀 파일 내 **'상세뉴스목록'** 시트 탭에서 상세하게 확인하실 수 있습니다.

## 4. 사용 예정 기술 스택 (Tech Stack)
* **Language**: Python 3.x
* **Browser Automation**: Playwright (Async Python API)
* **HTML/PDF Parsing**: PyMuPDF (fitz), BeautifulSoup4, requests
* **OCR Engine**: EasyOCR (무등일보 지면 이미지 판독용)
* **Data Processing**: OpenPyXL
* **CI/CD & Scheduler**: GitHub Actions (Ubuntu Environment)
